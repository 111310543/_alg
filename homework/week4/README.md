# 通用迭代法框架與演算法應用 (Iterative Framework)

本文件介紹了一個以 Python 實作的「通用迭代法框架」，以及如何使用此單一框架來解決從數值分析、機器學習到微分方程等九個不同領域的經典問題。

## 1. 核心概念：通用迭代框架

在許多數學與計算領域中，我們常常會遇到無法直接求出解析解（Analytical Solution）的問題。這時，我們會使用「迭代法」（Iteration Method），從一個初始猜測值開始，不斷重複套用某個規則，讓結果一步步逼近真實答案。

這個框架將所有迭代過程抽象化為三個核心元素：
1. **狀態推進函數 (`transition_func`)**：決定如何從當前狀態計算出下一個狀態。
2. **終止/收斂判定函數 (`is_converged`)**：決定何時停止迭代（例如新舊狀態差異極小）。
3. **初始狀態 (`initial_state`)**：迭代開始的起點。

### Python 核心實作 (`iterative.py`)

```python
import numpy as np

def generic_iterator(transition_func, is_converged, initial_state, max_iter=1000):
    """
    通用迭代法框架
    :param transition_func: 狀態推進函數 g(state) -> next_state
    :param is_converged: 終止/收斂判定函數 is_converged(state, next_state, iteration) -> bool
    :param initial_state: 初始狀態（純量、向量、矩陣或 Tuple）
    :return: 最終狀態, 實際迭代次數
    """
    state = initial_state
    
    for iteration in range(max_iter):
        next_state = transition_func(state)
        
        if is_converged(state, next_state, iteration):
            return next_state, iteration + 1
            
        state = next_state
        
    print("  [警告] 達到最大迭代次數仍未完全收斂")
    return state, max_iter
```

藉由將「推進邏輯」與「收斂判斷」分離，這個框架可以套用在幾乎任何符合 $x_{k+1} = g(x_k)$ 形式的演算法上。

## 2. 演算法實作範例總覽

以下列出可以使用此框架實作的九個經典演算法，以及它們對應的應用領域和工作原理：

### 數值求根與線性代數
* **二維不動點迭代法 (Fixed-Point Iteration)**
  * **用途：** 求解線性或非線性聯立方程式的根。
  * **原理：** 將問題改寫為 $X = g(X)$ 的形式，重複計算 $X_{k+1} = g(X_k)$ 逼近不動點。
* **牛頓法求根 (Newton's Method)**
  * **用途：** 快速尋找非線性方程式的根。
  * **原理：** 利用函數的切線來逼近根。推進公式為 $x_{k+1} = x_k - \frac{f(x_k)}{f'(x_k)}$，具備極快的二次收斂速度。
* **高斯-賽得爾法 (Gauss-Seidel Linear Solver)**
  * **用途：** 求解大型線性代數方程組 $Ax = b$。
  * **原理：** 在計算未知數的新值時，立刻使用其他已更新未知數的最新值，收斂速度通常優於傳統雅可比法。

### 矩陣運算與特徵值
* **冪次迭代法 (Power Iteration)**
  * **用途：** 尋找矩陣中絕對值最大的特徵值及其對應的特徵向量 (PCA 核心)。
  * **原理：** 不斷將矩陣乘以一個初始向量，並在每次迭代後將向量單位化。
* **QR 演算法 (QR Algorithm)**
  * **用途：** 計算矩陣的**所有**特徵值。
  * **原理：** 反覆對矩陣進行 QR 分解，然後將 R 和 Q 反向相乘，最終收斂為對角線包含特徵值的上三角矩陣。
* **PageRank (網頁排名)**
  * **用途：** 評估網頁的重要性（早期 Google 搜尋引擎核心）。
  * **原理：** 本質為冪次迭代法，模擬隨機衝浪者在網頁間跳轉，計算出穩態機率分佈。

### 微分方程與機器學習
* **龍格-庫塔法 (RK4 ODE Solver)**
  * **用途：** 數值求解常微分方程式（ODE）。
  * **原理：** 在每個時間步長內計算四個不同的斜率取加權平均。這是一種從時間 $t$ 迭代到 $t+h$ 的狀態轉移。
* **K-Means 聚類 (Hard EM)**
  * **用途：** 無監督機器學習中的資料分群。
  * **原理：** 交替進行 E-step (計算距離並分配標籤) 與 M-step (重新計算群集中心)。
* **EM 演算法 (Expectation-Maximization)**
  * **用途：** 估計帶有隱藏變數的統計模型參數（如雙硬幣機率問題）。
  * **原理：** 採用軟性機率分配，交替計算期望機率權重與更新估計參數。

## 3. 迭代法的收斂特性比較

評估迭代法好壞的一個重要指標是**收斂階數 (Order of Convergence)**，它代表每次迭代能將誤差縮小多少倍。

| 演算法特性 | 不動點迭代法 (Fixed-Point) | 割線法 (Secant) | 牛頓法 (Newton) |
| :--- | :--- | :--- | :--- |
| **收斂階數 $p$** | $p = 1$（線性收斂） | $p \approx 1.618$（超線性） | $p = 2$（二次收斂） |
| **運算代價** | 僅需計算 $g(x)$ | 僅需計算 $f(x)$ | 需計算 $f(x)$ 與導數 $f'(x)$ |
| **優缺點分析** | 實作簡單，但若需高精度則耗時較長。 | **性價比極高**，免算導數，是許多工業標準(如布倫特法)的底層。 | 只要靠近根，精確度呈爆炸性成長（小數位數翻倍），但需微積分。 |

## 4. 高維度最佳化：從牛頓法到 L-BFGS

在現代機器學習中，要最佳化百萬參數的模型，無法直接使用牛頓法，因為計算二階導數（海森矩陣）極其耗時且佔用記憶體。這催生了基於迭代框架的**擬牛頓法**：

* **BFGS 演算法**：多維度空間的「割線法」。它不計算真實的二階導數，而是透過「歷次迭代的梯度變化」來拼湊出近似的海森矩陣反矩陣，將複雜度從 $O(n^3)$ 降至 $O(n^2)$。
* **L-BFGS (有限記憶體 BFGS)**：進一步優化，只記住「最近幾步」的歷史軌跡，透過雙迴圈遞迴推演出前進方向。它免微積分、免算反矩陣、記憶體需求極低，是大規模傳統機器學習模型的最佳化王者。
