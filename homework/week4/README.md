# 數值方法與最佳化演算法：從基礎迭代到擬牛頓法 (L-BFGS)

這份文件彙整了數值分析與最佳化領域中的核心問題，探討如何透過「迭代」逐步逼近問題的真實解，並比較不同演算法在收斂速度、計算成本與適用場景上的差異。

## 議題一：如何用迭代法求解方程式？

**問題：請用迭代法求解一個問題。**

以求解方程式 $x^3 - x - 1 = 0$ 的實數根（約為 1.3247，塑膠常數）為例。我們需要將方程式改寫成 $x = g(x)$ 的形式。不同的改寫方式會導致完全不同的收斂結果。

1. **直接移項**：$g_1(x) = x^3 - 1$ (會發散)
2. **開三次方**：$g_2(x) = (x + 1)^{1/3}$ (線性收斂)
3. **牛頓法**：$g_3(x) = x - \frac{x^3 - x - 1}{3x^2 - 1}$ (二次收斂)

```python
# 初始猜測值
x1 = x2 = x3 = 1.0
# ... (迴圈執行迭代) ...
# g1(x) 發散，g2(x) 緩慢逼近，g3(x) 在 4 次迭代內達到極高精度。
```

這背後的成敗取決於迭代函數在根位置的**導數絕對值 $|g'(x)|$**。當 $|g'(x)| < 1$ 時才會收斂，而牛頓法巧妙地讓根附近的導數值為 0，實現極速收斂。

## 議題二：迭代法的通用框架與跨領域應用

**問題：各種經典迭代法是否能用統一的程式碼框架表示？**

可以。迭代法的核心可以抽象化為：`初始狀態`、`狀態推進函數 (Transition)` 與 `收斂判定 (Convergence)`。透過這個框架，我們能實作九大經典演算法：

1. **二維不動點迭代法**：解聯立方程式。
2. **牛頓法**：非線性方程式求根。
3. **高斯-賽得爾法 (Gauss-Seidel)**：解線性代數方程組 $Ax=b$。
4. **冪次迭代法 (Power Iteration)**：求矩陣主特徵向量 (PCA/SVD 基礎)。
5. **QR 演算法**：計算矩陣的所有特徵值。
6. **龍格-庫塔法 (RK4)**：解常微分方程式 (ODE)。
7. **PageRank**：計算網頁權重 (本質為冪次迭代)。
8. **K-Means 聚類**：硬性 EM 演算法，資料分群。
9. **EM 演算法**：軟性機率分配，估計隱藏變數。

## 議題三：評估收斂速度的指標

**問題：請解釋迭代法的『收斂階數』(Order of Convergence)，並比較牛頓法與不動點迭代法。**

**收斂階數 ($p$)** 是衡量演算法「逼近真實答案速度」的指標。定義為 $\lim_{n \to \infty} \frac{e_{n+1}}{(e_n)^p} = C$。

| 特性 | 不動點迭代法 | 牛頓法 |
| :--- | :--- | :--- |
| **收斂階數** | **$p = 1$（線性收斂）** | **$p = 2$（二次收斂）** |
| **精度增長** | 每次迭代增加「固定數量」的準確小數位 | 每次迭代準確的小數位數會「翻倍」 |
| **代價** | 僅需計算 $g(x)$ | 需計算導數 $f'(x)$，且對初始值敏感 |

## 議題四：免微積分的快速求根法

**問題：如果方程式很難微分解出 $f'(x)$，有沒有能保持快速收斂，又不需要計算導數的演算法？**

替代方案是**割線法 (Secant Method)**。它不使用切線（導數），而是取最近的**兩個點**連成「割線」，用割線斜率來近似切線斜率。

*   **迭代公式**：$x_{n+1} = x_n - f(x_n) \frac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})}$
*   **收斂階數**：$p = \frac{1 + \sqrt{5}}{2} \approx 1.618$ (黃金比例，超線性收斂)。
*   **優勢**：每次迭代只需計算 1 次函數值，性價比極高。

在現代工業標準中（如 Python `scipy`），通常使用**布倫特法 (Brent's Method)**，它結合了割線法（極速收斂）與二分逼近法（絕對穩定）的優點。

## 議題五：高維度機器學習中的最佳化

**問題：在機器學習中，如果無法計算海森矩陣 (Hessian)，常用的『擬牛頓法 (如 BFGS)』是如何運作的？**

牛頓法在多變數最佳化中需要計算龐大的二階導數矩陣（海森矩陣 $H$）及其反矩陣 $H^{-1}$，時間複雜度高達 $O(n^3)$，在機器學習中不可行。

**擬牛頓法 (BFGS) 的核心理念：**
它是多維度空間的「割線法」。利用**相鄰兩步的「位置變化量」與「梯度變化量」**，來逐步逼近（近似）海森矩陣的反矩陣 $B \approx H^{-1}$。
*   **優勢**：免算二階導數、免算反矩陣，計算複雜度降至 $O(n^2)$。

**L-BFGS (Limited-memory BFGS) 的進化：**
為了解決百萬參數模型記憶體不足的問題，L-BFGS 不儲存 $n \times n$ 的近似矩陣，而是只記住「最近 $m$ 步 (通常 5~20)」的歷史向量，透過**雙迴圈遞迴**動態推演出前進方向，將記憶體與時間複雜度雙雙降至 $O(m \times n)$。

> **實務應用：** 深度學習因雜訊大且非凸，主流仍為 Adam / SGD；但對於傳統機器學習（如邏輯迴歸、CRF）或科學計算，L-BFGS 依然是最強的預設演算法。
