# 經典搜尋演算法與應用 (Search Algorithms in Practice)

本專案展示了多種人工智慧與電腦科學中常見的搜尋問題，並使用不同的搜尋演算法（DFS, BFS, A*）進行求解。以下是每個演算法的核心概念與適用場景說明。

## 1. 深度優先搜尋 (DFS, Depth-First Search)
* **核心概念**：優先往深處探索，直到遇到死路才進行「回溯 (Backtracking)」。實作上常依賴遞迴或堆疊 (Stack)。
* **應用場景**：
  * **老鼠走迷宮**：只需找到「任意一條」可行路徑時，DFS 的記憶體消耗較少。
  * **八皇后問題**：需要在龐大的狀態空間中尋找所有合法解，且需要頻繁回溯狀態時，DFS 是最佳選擇。

## 2. 廣度優先搜尋 (BFS, Breadth-First Search)
* **核心概念**：像水波一樣向外擴展，逐層探索所有的可能性。實作上依賴佇列 (Queue)。
* **應用場景**：
  * **狼羊甘藍菜過河問題**：因為無權重圖中，先被探索到的目標狀態必然是「最短步數 (最佳解)」，適合用來找尋最少步驟的過河策略。
  * **Lee Algorithm (IC 繞線基礎)**：在早期的電路佈線中，BFS 保證能找到線路間最短的曼哈頓路徑。

## 3. A* 搜尋演算法 (A-Star Search)
* **核心概念**：結合了 Dijkstra 演算法的實際成本（g）與貪婪搜尋的預估成本（h），計算方式為 `f(n) = g(n) + h(n)`。利用優先佇列 (Priority Queue) 優先探索最有希望的路徑。
* **應用場景**：
  * **NPC 搜尋玩家**：在遊戲地圖中，A* 能有效避開障礙物，並且比 BFS 探索更少的節點就能找到最短路徑。
  * **現代 IC 繞線**：相較於暴力的 Lee 演算法，A* 搭配擁擠度權重 (Congestion penalty) 是現代迷宮繞線 (Maze Routing) 的核心基石。
